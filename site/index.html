ONE PATTERN FILE. MANY POSSIBILITIES.

Made for the pipeline.

Fetch domain patterns and search a file:

grep -E -f <(curl -s {{SITE_URL}}/domains) file1

Or keep your existing pipeline:

cat file1 | grep -E -f <(curl -s {{SITE_URL}}/domains)

A few useful details

These patterns select whole lines. Boundary characters are part of the match, so -o is not a clean extractor.

<(...) needs Bash or Zsh. Use LC_ALL=C for predictable ASCII matching. /ips currently means IPv4 only.

Using it in a script?

Download and check the pattern before running grep: a failed curl inside <(...) does not stop grep. Use curl -fsS to report download errors. Keep a local copy for repeatable results.
